# Coop3D 论文复现差异与数学实现审计

审计日期：2026-10-21。结论先行：当前代码是借用 Xu 的部分动力学、网络宽度和 PPO 超参数的**三维协同巡检导航基准**，不能称为 APH-MAPPO 研究任务的完整复现。本轮未发现并可复现的 PPO/GAE 算式、价值头索引、动作顺序或 RK4 系数 Bug，因此没有修改训练公式、环境、Reward 系数、gamma 或任务难度。

发现一个可构造验证的表征缺陷：当前 90D Critic 状态不含时间，而有限时域任务和 terminal reward 明确依赖时间。它属于任务建模/价值函数输入限制；250 步截断是否应继续 bootstrap 也需与目标语义一起决定，不能未经实验直接归咎于 PPO。本轮不更换状态维度或旧模型接口。

用户报告的 200000 步模型及其 50 局评估轨迹没有出现在本地工作区。不能对其失败原因给出实证归因。详见 [trajectory_diagnosis.md](trajectory_diagnosis.md)。

### 4.1 动作、概率和熵

三动作独立：`logπ(a|o)=Σ_k log Beta(a_k;α_k,β_k)`，联合微分熵 `H=Σ_k H(Beta_k)`。代码 `networks.py:40,44` 恰在最后动作维求和，不跨UAV求和。PPO sample 用 `.sample()` 并在 `no_grad` 内执行是 score-function PPO 的正常用法，不需要 SAC 的 `rsample()`。

物理仿射映射 Jacobian 的行列式为 `2π*3*8=48π`，新旧密度比的常数消去。物理熵比归一化熵多 `log(48π)` 常数；缺少这个常数不改变当前固定熵系数的梯度。Beta 微分熵为负本身不是错误（X p.11 §IV-D2也明确解释）。

`trainer.py:112–114` 把取样夹至 `[1e-6,1-1e-6]` 后重新计算旧logp，采样/存储/训练使用同一个数值动作，未发现新旧动作错配。不过严格而言夹紧后的分布在边界产生质量点，用连续Beta密度计算这些点只是一种数值近似；本地无原始训练动作证据，不能量化200000步时边界触发率。alpha/beta>1的当前初始化使此概率很小，不据此把失败归因于clip或更改算法。

### 4.2 PPO 与价值

`ratio=exp(logπ_new-logπ_old)`，`L_policy=-mean(min(ratio*A, clip(ratio,1-ε,1+ε)*A))`，`L_actor=L_policy-c_H*mean(H)`。正、负优势都使用相同min，符号正确。全体有效样本的优势用总体标准差（unbiased=False）和1e-8归一化，无无效槽参与。极小批中的零优势是该归一化的结果，不等于优化器损坏。

Critic按原始UAV槽位 gather，flatten/expand 的顺序一致；不是把某一个个体回报训练到所有五头。无效个体先剔除，无效global槽位先清零；未用输出头没有该批直接梯度（共享干仍受其他头训练）。Actor/Critic参数不共享，分别Adam和梯度限幅，不互相覆盖梯度。

新增独立已知答案测试：ratio=(1.4,.7,1.1)、A=(-2,1,3)，policy=-.4，entropy平均=.2且系数.1时actor total=-.42；V=(1,2,3)、return=(-1,3,6)时½MSE=7/3。另测标准化优势 `(-8,1,7)/sqrt(38)`。直接走实际 `update()`，三个UAV头及两个闲置头的梯度经核对，非复制旧实现自证。

### 4.3 GAE 和边界

设 c/n 是当前/后继个体mask，d=terminated，q=truncated。当前实现：

```text
bootstrap = c & n & !d
continuation = bootstrap & !q
delta = r + gamma * where(bootstrap, V(real_next), 0) - V(current)
A_t = where(c, delta + gamma*lambda*where(continuation,A_{t+1},0), 0)
R_t = where(c,A_t+V(current),0)
```

- 真终止或个体失效：无下一状态自举；失效当步仍有当前reward。
- 时间截断：真实末态自举，递推不进入新局。vector同时保存 `transition_states` 与 reset后的 `states`，collector使用前者。
- rollout尾：不跨buffer递推，但有真实后继V。
- 最后不足10个worker的联合预算：未执行worker填零并mask=0，没有假转移或超过预算。

代码对上述规则是自洽的。**需要进一步实验验证**的是：有限250步的任务目标是否真的允许估计时限后的价值。如果250步是物理任务截止而非采样器人为截断，通常需要以剩余时间定义有限时域价值，并在真实截止时不自举。当前没有时间输入，不能把“Gym式truncated”自动等同于正确的任务目标；Xu式(27)也没有解决这里的超时δ歧义。本轮没有自行变更该建模选择。

### 4.4 真实采样和优化次数

当前默认 E=10,H=250：每完整update为2500个**联合环境步**；无失效时3机为7500个有效个体样本，5机为12500。epochs10、mini128产生分别 `10*ceil(7500/128)=590`、`10*ceil(12500/128)=980` 次Actor更新，同时有同次数Critic更新。尾mini分别76、84个体。失效使有效样本下降，预算本身仍按联合步计。

若200000步运行确实使用此默认配置且从0训练，则是80个rollout/update，不是200000次优化；这个条件尚未用缺失的真实checkpoint确认。X p.8表III的E=10,H=1500是15000联合步/rollout（3机45000、5机75000个体），不等于当前mini或episode长度。论文5000局也不能简单换成200000步；每局长度变化，不在缺日志时臆算确切预算。

训练优化指标是每个mini的等权均值，尾mini也占一份权重；这影响日志总体均值的精确解释，不影响各mini实际损失或梯度。本轮没有再次美化/调整日志。
