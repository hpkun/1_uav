# 地面设施防护场景：v3 可复核建模说明

## 1. 研究任务和版本界限

本配置将保护对象定义为**地面小型设备或设施及其上方核心防护空域**，而非悬空目标点。三维运动仿真仍属于低速小型多旋翼的高层闭环速度响应模型，不表示已经实现真实机体动力学、接触毁伤或空域实际部署。保留旧版 `InterceptionConfig()` 的球形参数供数学与历史回归测试，新场景必须显式指定 `configs/interception_ground_facility_v3.json`。版本标识升级为 `uav-interception-v3.0.0`，旧 v1/v2 存档不可直接作为新环境训练权重恢复；已有模型文件不迁移、不覆盖。

| 原成功捕获带 | 1.1–3.0 m，低相对速度持续 0.5 s | **非接触式抽象捕获，未修改为机体撞击成功** |
| 单回合 | 1000 × 0.1 s = 100 s | 工况假设 |

**来源和选择边界：**

- DJI Mini 4 Pro 官方规格：普通模式水平最大速度 12 m/s、最大上升和下降速度均为 5 m/s。该商品是**量级参考**，不意味着它具有拦截任务能力。https://www.dji.com/mini-4-pro/specs
- Serra-Gómez 等，2023，*Autonomous Robots*：在 Parrot Bebop 2 三维多机碰撞规避实验中采用半径 0.30 m 的球形碰撞包络、最大速度 4.25 m/s。体现碰撞包络是**模型参数**，不等于物理损毁阈值。https://doi.org/10.1007/s10514-023-10127-3
- *An Adaptive Cylindrical-Pruning Decision Tree Method for Conflict Detection During Low-Altitude Multi-UAV Operations*（2026）：使用柱状区域区分水平安全范围与垂直范围。本文的保护柱体是**地面设施任务区域**，不是该论文的无人机碰撞安全区，不应把两者等同。https://www.mdpi.com/2226-4310/13/7/652

12 m、22 m、85–115 m、2.5 s、0.25 m **不是上述论文或官方资料直接给出的标准拦截参数**。它们需要后续按目标设施尺寸、平台实物包络、响应测量和难度敏感性实验重新校准。不得凭胜率挑选唯一参数并宣称其具有通用现实性。

## 3. 事件与动力学语义

保护区突破（仅基于入侵 UAV 中心）：
```text
horizontal = hypot(x - cx, y - cy) <= 12
vertical = 0 <= z <= 22
breach = horizontal AND vertical
```

使用连续时间窗口交集判定入侵的首次发生时刻，而不是只检查每个 0.1 秒步的终点。因此高空从区域上方掠过、但从未低于 22 m 的 UAV **不算区域突破**；从区域正上方下降并穿过顶面则算突破。下方飞出合法飞行空域应由越界事件单独处理。

速度命令先投影到三维总速度球，再独立裁剪 z 分量。其解析积分公式保持不变：
```text
p_dot = v
v_dot = (v_cmd - v) / tau
```
垂直速度裁剪对合法初态与后续解析积分均保持封闭。此模型不额外提供机体角速度、独立加速度限制或对真实姿态内环的验证。

两机接触仍由球形几何包络重叠触发 `collision`，并按原安全事故处理；原有 `capture` 事件继续表示“满足安全距离带、相对速度和停留时间要求的抽象捕获”，**不是直接撞击、毁伤或反制能力的证据**。

## 4. 使用、测试和验证

```bash
python -m algorithm.interception validate --env configs/interception_ground_facility_v3.json --scenario random --seed 42

python -m algorithm.interception run --env configs/interception_ground_facility_v3.json \
  --scenario random --policy random --episodes 2 \
  --out outputs/ground_facility_v3/random_check

python -m pytest -q tests/test_ground_facility.py tests/test_interception.py tests/test_interception_replay.py
```

运行前应保证输出目录不存在。新的研究训练和评估应放在独立目录，不能复用旧场景的模型与统计；若有评估模型，须使用同一新场景配置从头训练。
