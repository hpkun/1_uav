# Implementation Plan

当前状态：动力学、动作、同步战斗、1v1、固定同构 2v2、归一化、诊断、规则控制器、镜像工具、2024 式（21）—（25）及前馈 CTDE MAPPO 已实现。正式多训练种子同构实验已经执行；结果证明训练与评估链路可复现，但没有证明所有场景均已收敛。异构、3v2、GRU、注意力、迁移和零样本仍不在本轮范围。

1. 动力学、动作、同步推进：已完成。
2. 论文 2023 距离/高度/稠密奖励及 2024 多机终局奖励校准：已完成。
3. 1v1 观测归一化与毁伤统计语义校准：已完成。
4. 安全几何追踪、完整 1v1 策略矩阵：已完成。
5. 同构 2v2 局部观测、全局状态、目标分配、同步伤害、奖励和完整环境：已完成。
6. 2v2 规则评估和轨迹可视化：已完成。
7. 前馈 CTDE MAPPO、active/action mask、截断 bootstrap、ValueNormalizer、原子 checkpoint：已完成并回归测试。
8. 1v1 五种子、balanced 三种子、2v2 三种子及终局奖励消融：已完成；保留完整 checkpoint 与聚合指标。
9. 下一阶段进入 3v2 前：优先处理 2v2 高 timeout、训练后期退化、balanced 1v1 缺少稳定学习趋势，并扩大终局奖励消融的种子数。
10. 同构 3v2 论文规模复核：完成上述稳定性问题后再进入。
11. 异构、多传感器、雷达、循环/注意力网络和迁移：不在当前计划范围。
