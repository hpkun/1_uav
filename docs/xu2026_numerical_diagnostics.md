## 3. 积分失败与旧巡检Reward

仅用既有reset覆盖构造诊断夹具：三机v=100、γ=89°，横向间隔10000m；各自目标在初始速度反方向1000m，初始高度3000m、目标高度约2000.152m。保持原250步截止、原分配/完成/奖励规则。配平健康机每步远离其目标25m，始终无到达/近距/成功事件。不是新增训练任务、采样分布或调参实验。

解析健康每步：progress=2×(−25)/1000=−.05，efficiency=−.01，总计−.06。首步积分失败用正常范围内控制`[μ,ζ,ζ̂]=[0,1,8]`跨越坐标极点，保留原状态并失效；其progress=0、efficiency=−.01。注入失效仍按原顺序**先正常积分，再注入**，故首步有−.05进度项。

|案例|回合长度/结束|每机累计回报（解析值）|progress累计|efficiency累计|
|---|---|---|---|---|
|正常|250，truncated|[−15,−15,−15]|[−12.5,−12.5,−12.5]|[−2.5,−2.5,−2.5]|
|单机积分失败|250，truncated|[−.01,−15,−15]|[0,−12.5,−12.5]|[−.01,−2.5,−2.5]|
|全机积分失败|1，terminated|[−.01,−.01,−.01]|[0,0,0]|[−.01,−.01,−.01]|
|单机注入失效|250，truncated|[−.06,−15,−15]|[−.05,−12.5,−12.5]|[−.01,−2.5,−2.5]|
|全机注入失效|1，terminated|[−.06,−.06,−.06]|[−.05,−.05,−.05]|[−.01,−.01,−.01]|

全部案例的completion/separation/terminal均为0。实际返回reward为float32，`EpisodeAccumulator`按原口径累计：正常每机 **−14.999999664723873**（相对−15误差3.3527613e−7）；积分失败 **−.009999999776482582**（误差2.2351742e−10）；注入失效 **−.05999999865889549**（误差1.3411045e−9）。与“float32每步值再累计”的预期逐值完全一致；分项float64的解析误差也在JSON中保留。episode_return仍按全部3个槽平均，未换成存活机平均。

这是明确反例：**在此状态/后续行动下，提前失效比继续退离目标的累计回报高。** 最小一步比较已经是失败−.01高于健康/注入−.06；时间截止前缀还会继续积累负成本。它证明存在逃避未来负回报的激励，不证明训练策略已经学会主动利用失效，也不说明失效优于成功导航。

当步current_mask为[1,1,1]，单机失效next_mask=[0,1,1]，全失效next_mask=[0,0,0]。本步efficiency仍按current有效性扣除；progress比较同一前分配对象；separation/terminal按next有效性。失败后本机未来奖励/损失样本归零。

GAE人工V=1、后继V=2：失效机当步A=r−1、R=r，后继价值及carry排除；下一步已失效槽A/R=0。全失效为真终止；正常250步截止仍按现有truncated语义自举真实末态、不跨reset递推。没有修改这一时域假设，没有加死亡/积分失败惩罚。

## 5. 新增指标与不变性

旧`policy_loss/actor_total_loss/actor_loss/critic_loss/entropy/approx_kl/clip_fraction/gradient_norm/valid_samples/optimizer_steps/update`含义保持；新增字段集中在独立更新器返回的`numerical_diagnostics`，巡检返回指标不扩张。

|字段|定义|
|---|---|
|`per_uav_valid_samples` / `active_uav_count`|每个实际UAV槽的current mask有效数；计数>0的槽数|
|`advantage_before/after`|各机有效优势的有限性、min/max/mean/总体std、分位数；空槽为null统计，不填假0样本|
|`singleton_uavs` / `normalized`|恰有1个有效样本的槽号及是否启用原标准化|
|`per_uav_minibatches`|本次所有epochs内，每机至少出现一次的minibatch数量|
|`actor_gradient_norm/critic_gradient_norm`|每小批裁剪前全网络L2范数的统计；旧`gradient_norm`仍为两范数的原合成均值|
|`*_gradient_clip_fraction`|按本机PyTorch实际系数`max_norm/(norm+1e−6)<1`计数；精确等于阈值时微小裁剪也计入，已有边界测试|
|`tanh`|在**已有有效样本forward**上的两层饱和率、有限性及实际求值单元数；无额外随机采样或forward|
|`beta_parameters` / `beta_actions`|当前Actor变换后的α/β范围及有限性；有效动作范围/有限性；人工自定义模型无该结构时标available=false|
|`excluded_invalid_positions` / `invalid_samples_in_loss`|被mask排除的位置数量；筛选后训练样本无失效项（由不变性测试进一步验证）|
|`status`|ok、skipped_no_valid_samples；异常时`last_update_diagnostics`记录rejected及原因，原异常继续抛出|

诊断开关对照使用同一batch/RNG，模型参数、两Adam状态、随机状态、所有旧指标均**零容差一致**。只读诊断另检查已有梯度、模式和forward输出不变，异常也恢复RNG/移除hooks。空批和非有限有效奖励的拒绝均不改变模型/Adam/RNG。checkpoint中未保存新诊断属性；原身份拒绝与完整恢复回归继续通过。

`valid_samples`仍是有效个体样本数，新各机数之和与它一致；`sampled_steps`仍表示采样器执行的joint transitions。独立数组更新器没有采样器，以上所有案例的sampled_steps均为0，没有虚构环境步数。
