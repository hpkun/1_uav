# 表VII快速战败诊断与有符号观测消融

2026-10-26。本轮仅只读诊断旧模型、增加一个独立观测消融及小规模CUDA验收，未运行正式2500/5000回合训练，未覆盖历史模型或评估文件。

## 诊断来源与计数方法

模型：`outputs/headon_norm_2500/headon_xu_norm_3v3/seed_1/latest.pt`，2500完成回合、fixed_scale_v1、Xu paper Reward。使用表VII `head_on_3v3` 固定状态、确定性Beta均值，种子10010000～10010009。模型SHA256见诊断JSON，运行前后校验相等。十局结束步数/胜负均与历史 `evaluation_table_vii.json` 对应种子一致。

`tools/diagnose_headon.py`直接调用现有环境，不修改环境step、Blue决策、积分器、武器或奖励。几何取真实运动后状态，存活掩码与已有锁定计数取动作前快照，完整资格为非零距离≤2000米、自身三维alpha_i≤45°、目标三维alpha_j<90°；同时重建双方锁定阈值。所有实际击落的归属与重建结果核对，死亡清零后的计数也与真实环境核对。因此包含造成击落的那一步，没有从死亡后的掩码漏算事件。

统计的“两步达标数”是攻击者—目标对数；多个攻击者可同时对同一目标达标，但真实击落事件按现有最低ID归属规则只有一次，不能将达标对数当成击落数。同一步事件是同时结算，不把事件列表顺序解释为先后开火。APH前后分配分别记录，物理武器资格不依赖APH。

## 快速战败的证据

**1. 射程到达时，机头已严重偏离目标。** 十局共有1061个双方存活且距离在2000米内的配对步，Red三维alpha_i为53.79°～104.84°，均超过45°。仅看动作前APH目标的344个射程内样本，最小角也为53.79°。没有任何其他未分配Blue能被Red攻击锥覆盖。

**2. 持续大法向载荷伴随爬升，而非保持迎敌攻击姿态。** 1158个Red有效UAV步中，物理控制范围为mu∈[−81.52°,101.20°]、zeta∈[−0.0082,1.3628]、normal_load∈[3.0009,4.2894]，法向载荷均值3.6751。运动后gamma最高56.22°，psi为−41.24°～16.06°。

例如种子10010000的R0：第10步gamma=18.43°；第20步gamma=33.27°、对动作前目标alpha_i=42.86°，但尚未进入射程；第27步进入射程时gamma=40.64°、alpha_i=55.51°。此时R0高度6609.99米，目标6115.46米，机头向上而目标已在下方。第36步alpha_i进一步达86.00°。这是实际几何/控制失配，不是数值故障。

**3. 水平转向也常背离当前目标。** 以动作前固定目标水平LOS与真实水平速度的方位误差符号，对比本步实际水平航向增量，298步朝向、783步背离，77步近对准/无明显转向；非中性样本背离比例72.43%。极区样本应跳过，本次实际跳过0。目标在左时滚转均值−5.96°，目标在右时+17.59°。该指标描述局部转向，不等同于证明某步机动在全局策略上必然错误。

**4. 方向信息有可构造的真实观测歧义。** 独立环境探针中，Red=(0,0,6000)、Blue=(1500,±600,6000)，双方速度200、gamma/psi均0，其余槽死亡。左右场景的原始12维观测逐值相同，alpha_i均0.380506377弧度；旧Actor给出完全相同的mu=−0.463219弧度、zeta=0.685262、normal_load=5.668222。它无法仅凭这些相同输入区分这一对左右目标。此证据支持消融的必要性，但不能证明方向缺失是失败唯一原因，也不能预判新模型会提高胜率。

**5. 目标切换频繁，但没有证据表明它清除了Red有效锁定。** 存活目标间APH切换累计358次，典型R0/R1在第17～26步反复交换目标。Blue有99个完整威胁配对步来自Red当前未分配的Blue。现有武器对所有存活对独立计数，APH切换不会重置物理锁定；本次Red本来就没有任何完整攻击资格。没有调整APH或奖励反馈。

**6. 极区不是这十局的失败原因。** 双方|gamma|>60°的UAV步均为0，pole_entries=0、continuation_substeps=0、numerical_failure=0。较大爬升角使攻击几何恶化，但没有进入极区延续。

首个种子的首次真实击落为第37步B1→R1：攻击者位置(7411.44,5723.53,6424.02)，目标位置(6801.17,5606.04,7023.03)米；距离863.16米，Blue的alpha_i=13.25°、目标alpha_j=81.63°。第36、37步连续满足完整资格，按真实规则击落。

## 新消融的唯一变量

新增 `headon_xu_norm_signed_3v3`，family=observation_ablation，paper_experiment=false。与headon_xu_norm_3v3相比，训练配置完全相同，环境配置唯一差异为 `observation_encoding='signed_alpha_v1'`；默认旧模式为 `unsigned`。

`env/aircombat/observations.py`只在构造网络观测的第5字段时，将原无符号三维alpha_i乘以左右符号。水平速度由真实v/gamma/psi计算，保留cos(gamma)的符号。单位水平速度与单位水平LOS的叉积为正取+1（左），负取−1（右）。Critic由同一12维槽打包，固定尺度归一化仍在网络入口按pi缩放该角。Actor仍12D、Critic仍60D，死亡及补零槽全零，其他11个字段不变。

确定性边界约定：水平速度或水平LOS范数≤已有geometry_epsilon(1e-9)，或归一化叉积绝对值≤1e-12，统一取+1。零距离也按此正分支保留原始角；不乘0丢失三维角度的绝对值。该约定是实验性编码：左右分支切换、背向近±pi以及水平投影退化/垂直LOS附近可以不连续，不宣称是全局连续角度表示或Xu原方法。

APH、原始relative_geometry、姿态优势、Reward、武器和Blue均继续使用无符号角；没有改动这些模块。也未改变任何动力学、网络、Beta初始化、PPO/GAE、控制范围、head_on分布或训练种子。

编码字段进入config.json、experiment.json及checkpoint的env_config；现有严格恢复校验在加载参数前拒绝跨编码恢复，旧checkpoint缺少字段时解释为unsigned。默认新根目录outputs/headon_norm_signed_2500，与旧结果分开；已有覆盖保护保留。该实验排除Xu原论文37项计划和结果汇总。
