# Observation Definition

## Actor observation (11 dimensions)

固定顺序为：自身与敌机的 x/y 差、自身高度、三维距离、相对位置俯仰角、相对位置方位角、三维速度差、敌机逃逸角和自身攻击角。速度向量由标量速度、航迹倾角和航向角实时推导，不重复存储。

归一化使用 `2 * value / reference - 1`。水平量和距离参考 5000 米，高度参考 5000 米，角度根据定义使用 π，速度差参考平台最大/最小速度之差。默认裁剪到 `[-1, 1]`，`info["actor_observation_preclip_max_abs"]` 记录裁剪前的最大绝对值。

## Critic state (10 dimensions)

固定顺序为：距离、自身攻击角、敌机逃逸角、敌我高度差、相对位置方位角、航向差、航迹倾角差、速度差、自身生命值、自身与敌机生命值差。所有角度差在归一化前先映射到 `[-pi, pi)`。
