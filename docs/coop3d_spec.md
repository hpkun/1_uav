论文 rollout horizon 为 1500、episode 最多 250。本项目采用每次更新 rollout 250，作为独立 `horizon` 配置暴露，这是工程约定，不声称逐项复现论文实验。

## 动力学与积分

状态 `[x,y,z,v,γ,ψ]`、控制 `[μ,ζ,ζ̂]`：

```text
dx = v cos(γ) cos(ψ)
dy = v cos(γ) sin(ψ)
dz = v sin(γ)
dv = g (ζ - sin(γ))
dγ = g/v (ζ̂ cos(μ) - cos(γ))
dψ = g ζ̂ sin(μ) / (v cos(γ))
```

固定控制经典 RK4，默认 g=9.81、dt=.25 s。完整积分后速度限制 `[100,400]`、γ 限制 ±85°、ψ 环绕 `[-π,π)`。±85° 是数值稳定性假设，不是论文飞行包线。中间导数保护 γ 和分母：`v_safe=max(|v|,1e-6)`，`cos_safe=max(cos(clip(γ)),1e-6)`。输入状态非有限则明确抛错；积分结果非有限则保留上个有限状态并使 UAV 失效。记录 `speed_clips`、`gamma_clips`、`nonfinite_states`；裁剪计数按每 UAV 每次完整积分结果记账。

动作映射 `[2πa0-π,3a1-1,8a2]`。有效动作超范围则拒绝，失效动作忽略。无任务有效 UAV 使用 `[0,sinγ,cosγ]` 配平过载保持当前速度、γ、ψ，仍积分微分方程。巡航不保证绝对避碰；距离仍被记录并计入安全奖励。

## 分配、完成和失效时序

代价 `d/10000+0.2|wrap(atan2(dy,dx)-ψ)|/π-0.1p`，默认优先级 1，合法范围 `[0,1]`。每步有效 UAV 与未完成点做独占矩形 Hungarian，匹配数为两侧数量较小值，不复制任务列。最短增广路实现复杂度 `O(min(N,M)^2 max(N,M))`，不依赖 SciPy；测试用穷举验证最优性。相同代价按固定遍历顺序确定结果。`nearest` 全局距离对排序后贪心选独占匹配，同距按 UAV、点 ID；不使用航向或优先级。

step 顺序：保存当前状态/掩码/分配 → 积分 → 注入本步末失效 → 下一有效 UAV 步末位置判定完成 → 奖励与终止 → 重新分配 → 下一观测。

三维距离 ≤300 m 完成；不做连续线段穿球检测，不在 reset 时直接完成。任何有效 UAV 实际到达均可完成，包括未分配给它的点；同一点同一步由最低有效 UAV ID 完成，只奖励一次 10 分。重叠任务球可同一步各完成一次。失效当步仍保留控制转移、进度和时间奖励，但不参与步末到达判定。这些均为消除歧义的明确约定。

进度奖励依据动作前的同一个目标，防止重新分配产生距离跳变。新分配用于下一步观测与导航。无目标 UAV 不重复占用任务。

## 观测与集中状态

归一化使用下表精确公式，没有隐藏裁剪；远距离、高度可以超出 1：

|索引|特征|归一化|
|---|---|---|
|0|有效性|0/1|
|1|速度|`(v-v_min)/(v_max-v_min)`|
|2|航迹倾角|`γ/gamma_limit`，默认分母 85° 弧度|
|3|航向|`wrap(ψ)/π`|
|4|高度|`z/5000`|
|5,6,7|目标相对位置|`(waypoint-position)/10000`|
|8|三维目标距离|`norm(relative)/10000`|
|9|水平航向误差|`wrap(atan2(dy,dx)-ψ)/π`|
|10|有效分配|0/1|
|11|最近有效友机距离|`min(distance)/10000`，无友机则 0|

无任务的 5–10 项为 0；失效整行 12 项为 0。环境输出 N 行，集中状态按 ID 补足五行并展平，严格 60 维。Critic 接收 `[batch,60]`，输出 `[batch]`，没有焦点观测拼接。

## 五项奖励和终止

1. `progress=2*(d_before-d_after)/1000`，无任务为 0。
2. `completion=10*本步唯一完成事件数`。
3. `separation=-mean(max(0,1-d_ik/100))`，只对步末有效 UAV 及其有效友机计算，仅一架有效为 0。
4. `efficiency=-0.01`，动作前有效每步获得，此前失效为 0。
5. `terminal=20-floor(T/25)`，全部任务成功当步的有效 UAV 获得。

总奖励为五项之和，没有隐藏分量。纯函数 `compute_rewards` 接收前后状态、前分配、前后 mask、事件、T 和 success，可用记录重算。总 reward 返回 float32，分项保留 float64，允许正常舍入。

全部任务完成则 terminated/success；全部 UAV 失效且仍未完成则 terminated/all_inactive；达到步数上限且尚未 terminated 则 truncated。成功/失败优先于同一步超时。`incomplete` 始终表示尚未完成全部任务。结束后禁止继续 step，防止重复奖励。

## MAPPO、GAE 与断点

共享 Actor/Critic：128 Tanh →128 Tanh。Actor 输出 6 个参数，`softplus+1` 形成三维独立 Beta，log probability/entropy 均按三维求和。样本裁剪至 `[1e-6,1-1e-6]`，随后对实际执行样本重新计算并保存 log probability；评估取 Beta 均值。ratio=`exp(new_logp-old_logp)`。

Adam，Actor/Critic LR=3e-4，gamma=.954，lambda=.95，clip=.2，entropy=.001，epochs=10，minibatch=128，workers=10。自行补充：Adam eps=1e-5；梯度范数上限=.5；仅有效样本优势标准化（总体标准差+1e-8）；Critic `.5*MSE`；无价值限幅、无学习率退火、无 KL 提前停止；保留最后不足 128 的批次；PyTorch CPU 线程=1。

Critic 输出全局标量，广播作为各有效 UAV 的基线；个体保留各自奖励、GAE 和 return。Critic MSE 在有效个体样本上求平均，同一状态可有多个个体 return。这是全局标量价值与个体奖励之间的工程约定，不额外加入个体特征或另一套 critic。

当前 mask=m、下一 mask=m'、terminated=D、truncated=Q：

```text
δ_t = m_t * [r_t + gamma*(1-D_t)*m'_t*V(S'_t) - V(S_t)]
A_t = m_t * [δ_t + gamma*lambda*(1-D_t)*(1-Q_t)*m'_t*A_(t+1)]
R_t = m_t * [A_t + V(S_t)]
```

失效当步 m=1/m'=0，保留奖励但不自举；失效后从两种损失和优势标准化筛除。无有效样本不更新。terminated 不自举，truncated 用真实末观测自举，但切断跨局递推。rollout 边界使用保存的下一价值。

spawn 并行，worker i 第 e 局 seed=`base_seed+e*num_envs+i`；每个环境独立 RNG，遇到保留评估种子明确报错。自动 reset 观测与真实末观测分开保存，不将 reset 状态用于上一局自举。错误/超时传回主进程，退出回收 worker。

完整断点包含网络、Adam、更新数、最佳评分、配置、全部 RNG、worker 任务状态/分配/局数。恢复要求配置完全一致。评估种子与已使用训练种子独立。训练/评估入口在采样前强制 CUDA，无 CPU 降级。

## 场景、记录及限制

随机初始 UAV 水平 ±500 m、高度 2500–3500 m、速度 200–250 m/s、γ ±5°，ψ 朝向点均值并扰动 ±30°；点 x=5500–11000 m、y=±2000 m、z=2000–4000 m，初始距离主要约 5–12 km。友机初始三维间距 ≥200 m，10000 次采样失败报错。所有范围独立配置，使用环境 RNG。

记录 reset 和每个 step 的完整六维状态、实际控制、前后 mask/分配、点坐标/优先级/完成标志、友机间距、奖励及完成/失效事件。HTML 内嵌 Plotly 与 JSON，离线读取实际帧，不修改环境、不重算仿真。支持播放/暂停、滑块、视角旋转、轨迹、完成状态、分配线、逐 UAV 查询。

没有地形、能耗、传感噪声或碰撞损伤模型；接近只施加指定安全惩罚，不增加额外失效或终止规则。短程训练验证工程闭环，长期学习性能需要充分预算和多随机种子实验。
