# Experimental Assumptions

| 类别 | 项目内容 | 处理方式 |
|---|---|---|
| 论文明确参数 | 15 种动作、速度/过载/航迹角范围、初始生命值 | 原值写入 paper 配置 |
| 论文明确参数 | 攻击距离/角度、优势区距离/逃逸角、四档伤害概率和伤害值 | 原值写入 `base.yaml` |
| 论文明确参数 | 角度、稠密、速度、事件和终局奖励中附件给出的公式/数值 | 按给定公式实现 |
| 公式直接推导 | `physics_steps_per_action = decision_dt / physics_dt = 5` | 配置加载时强制校验为正整数 |
| 公式直接推导 | 左右转滚转角使 `3.5*cos(gamma)=1` | 使用 `±arccos(2/7)` |
| 项目约定 | 红蓝每个物理子步同步写回 | 避免状态更新顺序偏置 |
| 项目约定 | 同一决策步的双方伤害同步写回 | 避免红蓝先手偏置 |
| 项目约定 | 最大高度 5000 米 | 放在 `project_assumptions` 并生成越界事件 |
| 项目约定 | 机间碰撞距离默认为 0 | 论文未明确最小安全距离，本轮关闭；正值可启用 |
| 项目约定 | tail chase、head on、balanced random 的具体采样范围 | 用于可复现实验初始化，不声称为论文参数 |
| 项目约定 | 距离奖励在四个断点间采用连续分段线性函数，并加入 0.1 权重的有界接近项 | 附件未提供完整分段解析式；实现保证边界连续、无除零 |
| 项目约定 | 高度奖励在 `H_min/H_att/H_adv/H_max` 上采用连续梯形 | 附件只给断点，未给完整分段解析式 |
| 项目约定 | 几何追踪对手使用角度 1.0、攻击区间距离 0.6、高差 0.2 的代价 | 仅用于环境可学习性测试，不是论文预测式规则对手 |
| 缺失信息 | 论文预测对手四个子威胁函数 | 暂不实现，不宣称严格复现 |
| 未实现 | 同构 2v2、异构性能、有限雷达探测、强化学习算法 | 保留清楚的后续阶段边界 |

默认事件奖励模式为 `per_step`，同时统计攻击区/优势区持续步数和进入次数；可切换为 `on_enter` 防止持续占区重复奖励。DRAW 在环境结果中保持平局，默认训练奖励按失败处理，可通过 `draw_as_loss` 修改。
